# Palindrome Checker

## Overview
This project is a simple web-based application that checks whether a given word or phrase is a palindrome. A palindrome is a word, phrase, number, or other sequence of characters that reads the same forward and backward, ignoring spaces, punctuation, and capitalization.

## Features
- **Input Box**: Allows users to enter a word or phrase to check.
- **Check Button**: Users can click this button to check if the input is a palindrome.
- **Result Display**: After clicking the button, the result is displayed to let the user know whether the input is a palindrome or not.

## Technologies Used
- HTML5
- CSS3
- JavaScript

### index.html
Contains the structure and layout of the webpage, including the input field, button, and the result area.

### styles.css
Contains the CSS styles to style the HTML elements, including the background colors, borders, and text alignment.

### script.js
Contains the JavaScript code that implements the logic for checking if a string is a palindrome. It handles user input, removes unwanted characters, converts the string to lowercase, and compares it to its reversed version.

## Example

- **Input**: "madam"
- **Output**: "madam is a palindrome"

- **Input**: "hello"
- **Output**: "hello is not a palindrome"

## Notes
- This tool ignores spaces, punctuation, and case when checking if the input is a palindrome.
- If no input is provided, an alert will prompt the user to enter a value.
